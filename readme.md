# ⚔️ FINAL FANTASY XV — Cinematic Fan Website

A cinematic **Final Fantasy XV fan website** designed to bring the world of **Eos** to life through immersive visuals, animations, character showcases, story sections, combat features, Royal Arms, summons, and interactive 3D elements.

* 👑 Final Fantasy XV story and synopsis
* ⚔️ Character showcase

  * Ignis
  * Gladiolus
  * Prompto
  * Cor
* 🗡️ Royal Arms showcase
* 🔥 Combat system showcase
* 🌊 Astral summons

  * Leviathan
  * Bahamut
* 🌍 Explore the world of Eos

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Libraries & Tools

* **AOS** — Scroll-based animations
* **Lenis** — Smooth scrolling
* **Google Model Viewer** — Interactive 3D model rendering
* **HTML Canvas** — Particle animations

The project uses AOS for animated sections and Google Model Viewer for the interactive Engine Blade model.

## 📖 Website Sections

### 👑 The King

Introduces **Noctis Lucis Caelum** and his journey from prince to king, exploring themes of responsibility, sacrifice and destiny.

### 🛡️ The King's Guard

A showcase of Noctis and his companions, highlighting the bond between:

* Noctis
* Ignis
* Gladiolus
* Prompto
* Cor

### ⚔️ The Royal Arms

Explores the legendary weapons connected to the kings of Lucis and their significance to Noctis.

### 🗡️ The Engine Blade

Features an interactive 3D model of Noctis's iconic Engine Blade with:

* 360° rotation
* Camera controls
* Interactive 3D viewing

### 💥 Combat System

Showcases the unique combat styles of the main characters, including:

* Noctis — Warp and weapon switching
* Prompto — Long-range firearm combat
* Ignis — Tactical dagger combat
* Gladiolus — Heavy greatsword combat

### 🌊 Awaken the Gods

Explores the Astrals and their immense powers, featuring summons such as **Leviathan** and **Bahamut**.

### 🌍 The World of Eos

A visual journey through locations such as:

* Crown City
* Altissia
* Duscae
* Ancient ruins
* Various landscapes across Eos

### 🚘 The Regalia

A visual showcase of Noctis's iconic vehicle and its role in exploring Eos.

## ✨ Animations & Effects

The website uses several visual effects to create a cinematic experience:

* Scroll-triggered animations using AOS
* Smooth scrolling using Lenis
* Animated particles using HTML Canvas
* Scroll progress indicator
* GIF-based visual effects
* Interactive 3D model
* Image-based character and environment sections

The footer also contains a custom JavaScript particle system rendered through Canvas.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/final-fantasy-xv.git
```

### 2. Open the project

```bash
cd final-fantasy-xv
```

### 3. Run the website

Since this is a frontend project, you can simply open `index.html` in a browser.

For the best development experience, use **VS Code Live Server** or another local development server.
