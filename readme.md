# ⚔️ FINAL FANTASY XV — Cinematic Fan Website

A cinematic **Final Fantasy XV fan website** designed to bring the world of **Eos** to life through immersive visuals, animations, character showcases, story sections, combat features, Royal Arms, summons, and interactive 3D elements.

> **RECLAIM YOUR THRONE**

## ✨ Features

* 🎬 Cinematic landing page
* 👑 Final Fantasy XV story and synopsis
* ⚔️ Character showcase

  * Noctis
  * Ignis
  * Gladiolus
  * Prompto
  * Cor
* 🗡️ Royal Arms showcase
* 🔥 Combat system showcase
* 🌊 Astral summons

  * Leviathan
  * Bahamut
* 🌍 Explore the world of Eos
* 🚘 Regalia showcase
* 🗡️ Interactive 3D Engine Blade model
* ✨ Animated particle effects
* 📜 Scroll progress indicator
* 🎞️ Scroll-triggered animations
* 📱 Responsive visual layout

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Libraries & Tools

* **AOS** — Scroll-based animations
* **Lenis** — Smooth scrolling
* **Google Model Viewer** — Interactive 3D model rendering
* **HTML Canvas** — Particle animations

The project uses AOS for animated sections and Google Model Viewer for the interactive Engine Blade model.
